# Engagements &amp; staffing needs

## Purpose

Maintain engagements and state which roles, skills, dates and load each one needs staffed.

Needs: F1.

## User Stories

- F2.1 As an administrator, I create and edit an engagement with name, client, start date and end date.
- F2.2 As an engagement manager, I see the engagements I manage.
- F2.3 As an engagement manager, I add a staffing need to my engagement: role, required skills, dates and percentage load.
- F2.4 As an engagement manager, I edit or remove a staffing need.
- F2.5 As a resource manager, I see all engagements with their open (unfilled) staffing needs.
- F2.6 As an administrator, I close an engagement so it no longer accepts new allocations.

## Decisions

- An engagement has one or more engagement managers, chosen from the employees by the administrator when creating or editing the engagement. *assumed*
- A staffing need is filled when allocations cover its dates and load.
