# Allocation

## Purpose

Assign employees to engagements with dates and percentage load, and change or end those assignments.

Needs: F1, F2.

## User Stories

- F3.1 As a resource manager, I allocate an employee to an engagement with start date, end date and percentage load.
- F3.2 As a resource manager, I allocate an employee directly against an open staffing need.
- F3.3 As a resource manager, I change the dates or load of an allocation.
- F3.4 As a resource manager, I end or remove an allocation.
- F3.5 As a resource manager, I see employees ranked by skill match when filling a staffing need.
- F3.6 As an engagement manager, I see the allocations on my engagements.
- F3.7 As a resource manager, I view the change history of an allocation.

## Decisions

- Allocations cannot be made on a closed engagement.
- Allocations are not approved; the resource manager decides alone.
